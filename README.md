# seismic-activity-dashboard-R
This is a web-app (dashboard) built using the shiny package in R to visualize the historical seismic activity at Mt. Vesuvius. Specifically, I was interested in mapping temporal trends (frequency and magnitude) and trends in location. I made this as part of the TidyTuesday challenge :)

Dataset: Data Science Learning Community (2024). Tidy Tuesday: A weekly social data project. https://tidytues.day
